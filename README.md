## 0. 데이터 검증: delivery_status와 is_returned의 관계
**목적:** 배송이 지연(`Delayed`)된 주문에서 실제 반품이 많은지 확인하려 함

| delivery_status | is_returned = False | is_returned = True |
|---|---|---|
| Delayed | 294,983 | 0 |
| Delivered | 295,234 | 0 |
| In Transit | 293,793 | 0 |
| Returned | 0 | 115,990 |

- 전체 1,000,000건 중 반품은 115,990건(약 11.6%)
- `Returned` 상태만 반품(True)이고, 나머지 3개 상태에는 반품이 0건임
- 즉 `delivery_status`는 `is_returned`와 완전히 겹치는 열이라, 지연 여부와 반품의 관계는 이 열로 분석할 수 없음
- **결론:** 지연 → 반품 분석은 불가능하다고 판단함. 대신 배송 소요일인 `shipping_time_days`로 배송 경험과 반품의 관계를 분석함(1번)
- 로지스틱 회귀에서도 `delivery_status`는 반품 여부를 그대로 알려주는 열이므로 독립변수에서 제외함

## 1. 배송 기간과 반품의 관계 (배송 기간이 길수록 반품률이 증가하는가?)
   - t-test 검정을 통해 반품된 주문들의 평균 배송 기간(3.41일)과 반품 안 된 주문들의 평균 배송 기간(3.13일)을 비교함
   - Levene 검정 결과 두 그룹의 분산이 다르게 나타나(p<0.001), Welch's t-test를 적용함
   - t-test 결과 p<0.001로 두 그룹의 배송 기간 차이는 통계적으로 유의미함
   - 배송 기간이 1~5일까지는 반품률이 10.5~10.7%로 유사했으나, 6일(최장 배송, 99,818건)에서는 20.7%로 급격히 상승함
   - **결론**: 배송 기간과 반품률 사이에는 통계적으로 유의미한 관계가 있음. 다만 기간에 비례해 점진적으로 늘어나는 형태가 아니라, 최장 배송 구간(6일)에서만 반품 위험이 뚜렷하게 높아지는 계단형 패턴임


## 2. 상품 평점과 반품의 관계 (상품 평점이 낮으면 반품률이 높은가?)
   - t-test 검정을 통해 반품된 상품의 평균 평점(3.86)과 반품 안 된 상품의 평균 평점(3.94)을 비교함
   - Levene 검정 결과 두 그룹의 분산이 다르게 나타나(p<0.001), Welch's t-test를 적용함
   - t-test 결과 p<0.001로 통계적으로 유의미한 차이가 확인되었으나, 평균 평점 차이(약 0.07점) 자체는 크지 않음
   - 이상치 비율도 두 그룹 간 유사함(비반품 0.29%, 반품 0.30%)
   - 평점 구간별 반품률을 보면 3점 이상 구간(3점대, 4점대, 5.0점)은 약 10.9~11.0%로 거의 같지만, 2점대는 31.2%(30,074건), 1점대는 43.1%(51건)로 크게 높음
   - **결론**: 평균 차이는 작지만, 평점이 3점 미만인 상품에서 반품률이 약 3배로 뛰는 계단형 패턴이 확인됨. 다만 3점 미만 주문은 전체의 약 3%(30,125건)라 전체 반품 규모에 미치는 영향은 제한적임


## 3. 판매자 평점과 반품의 관계
**가설:** 판매자의 평점이 낮을수록 반품률이 증가하는가?

- t-test 검정을 통해 반품된 주문의 판매자 평균 평점(3.7528)과 반품 안 된 주문의 판매자 평균 평점(3.7497)을 비교함
- Levene 검정 결과 두 그룹의 분산이 유사하여(p=0.4216), 등분산 가정 t-test를 적용함
- t-test 결과 p=0.1680으로 통계적으로 유의미한 차이가 없음
- 두 그룹 모두 이상치 없음(각 0건)
- **결론:** 판매자 평점은 반품 여부와 통계적으로 유의미한 관계가 없는 것으로 나타남


## 4. 로지스틱 회귀 - 반품 영향 요인 종합 분석
**가설:** 배송 기간, 상품 평점, 판매자 평점, 할인율을 동시에 고려했을 때 각 변수가 반품에 미치는 영향은?

- 종속변수: `is_returned` / 독립변수: `shipping_time_days`, `rating`, `seller_rating`, `discount`
- 오즈비는 "해당 변수가 1단위 증가할 때 반품 **오즈**(반품 / 비반품 비율)가 몇 배가 되는가"를 뜻함 (확률 증가율이 아님)

| 변수 | 오즈비 | p-value | 해석 |
|---|---|---|---|
| shipping_time_days | 1.1028 | <0.001 | 배송 1일 증가 시 반품 오즈 약 10.3% 증가 |
| rating | 0.7668 | <0.001 | 평점 1점 증가 시 반품 오즈 약 23.3% 감소 |
| seller_rating | 1.0057 | 0.189 | 통계적으로 유의미하지 않음 |
| discount | 0.9995 | 0.024 | 유의하나 효과는 사실상 없음 (1%p당 오즈 0.05% 감소) |

- 모델 설명력: McFadden Pseudo R² = 0.0065 (매우 낮음)
- 변수마다 단위가 달라 오즈비의 크기를 직접 비교할 수 없으므로, 영향력 비교는 표준화(1 표준편차 기준) 결과로 판단함 (4-1 참고)
- 100만 건 표본에서는 거의 모든 변수가 p<0.05로 나오기 쉬우므로, 유의성보다 효과의 크기를 함께 해석함


### 4-1. 로지스틱 회귀 보강
- 배송 기간은 1~5일까지 반품률이 비슷하다가 6일에서만 뛰는 계단형이라, 배송일을 선형 변수로 넣으면 실제 패턴과 맞지 않음. 그래서 "최장 배송(6일) 여부" 더미 변수를 넣은 모델을 추가함
- 더미 모델의 `ship_longest` 오즈비: 2.2034 (p<0.001) → 6일 배송이면 반품 오즈가 약 2.2배
- Pseudo R²: 선형 배송일 모델 0.0065 → 더미 모델 0.0133 (약 2배로 개선되었으나 여전히 낮음)
- 표준화 오즈비(1 표준편차 변화 기준): 배송 기간 1.178(증가), 상품 평점 0.871(감소, 역수로 보면 1.148), 판매자 평점 1.004, 할인율 0.993
- 따라서 반품에 영향을 주는 변수는 배송 기간과 상품 평점이 비슷한 수준으로 가장 크고, 판매자 평점과 할인율은 거의 영향이 없음 (처음 오즈비 표에서는 평점이 가장 커 보였으나, 단위가 다르기 때문이었음)


## 5. 카테고리와 반품의 관계
**가설:** 카테고리에 따라 반품률이 다른가?

- 카테고리(범주형)와 반품 여부(범주형)의 독립성을 카이제곱 검정으로 확인함
- 카이제곱 통계량 29.63, 자유도 4, p<0.001
- 효과 크기 Cramér's V = 0.0054 (0.1 미만이면 관계가 매우 약함)
- 카테고리별 반품률 범위: 11.27%(Electronics) ~ 11.76%(Beauty)
- **결론:** 표본이 커서 통계적으로는 유의하지만, 반품률 차이가 0.5%p 이내이고 Cramér's V도 0에 가까워 카테고리는 반품과 실질적으로 관계가 없다고 판단함


## 판매량 분석
판매량은 **주문 건수**(행 1개 = 주문 1건)로 정의함. 수량(quantity) 열이 없기 때문임.
(아래 번호는 `main.py`의 섹션 번호와 같음)

### 6. 브랜드별 판매량
- 브랜드 개수: 12개, 판매량 1위: LG(83,882건), 최하위: H&M(82,412건)
- 1위 / 최하위 판매량 비율: 1.02배 → 브랜드 간 판매량 차이가 거의 없음

### 7. 월별 카테고리 판매량
- 구매일 범위: 2024-03-31 ~ 2026-03-31, 날짜 변환 실패 0건
- 2024-03은 3월 31일 하루치(1,400건)뿐이라 검정에서 제외함. 나머지 달의 월별 주문 건수는 38,035 ~ 42,842건으로 비슷함
- 월별 판매량 1위 카테고리가 달마다 계속 바뀌며 5개 카테고리가 모두 1위를 함. 카테고리별 비중도 매달 약 19.5~20.5% 수준
- 월 × 카테고리 카이제곱: χ²=89.09, 자유도 92, p=0.567, Cramér's V=0.0047
- **결론:** 월에 따라 잘 팔리는 카테고리가 달라진다는 근거가 없음 (계절성 없음)

### 8. 판매자 평점 구간별 판매량
- 판매자 평점(2.5~5.0)을 같은 폭의 5개 구간으로 나눠 구간별 주문 건수와 반품률을 확인함
- 구간별 주문 건수는 179,453 ~ 219,501건으로 차이가 나지만, 이는 구간 구성 때문임. 가장 낮은 구간(2.5~3.0)은 평점 값이 6가지(2.5, 2.6, …, 3.0)이고 나머지는 5가지이며, 양 끝값(2.5, 5.0)은 다른 값의 절반 정도(약 2만 건 vs 4만 건)만 존재함
- 구간별 반품률은 11.48% ~ 11.70%로 거의 같음
- **결론:** 판매자 평점에 따라 판매량이나 반품률이 달라진다는 근거가 없음

### 9. 지역별 브랜드 판매량
- 지역 5개(Delhi 200,649건, Bangalore 200,270건, Chennai 199,902건, Mumbai 199,874건, Hyderabad 199,305건)로 지역 간 주문 건수가 거의 같음
- 지역별 1위 브랜드: Bangalore는 Lenovo, Chennai와 Delhi는 HP, Hyderabad는 LG, Mumbai는 Sony
- 지역 × 브랜드 카이제곱: χ²=33.47, 자유도 44, p=0.876, Cramér's V=0.0029
- **결론:** 지역마다 1위 브랜드가 다르게 보이지만 점유율 차이가 매우 작고 통계적으로도 독립이므로, 지역에 따라 선호 브랜드가 다르다고 보기 어려움

### 10. 카테고리별 평균 할인율과 판매량
- 카테고리별 평균 할인율: Clothing 40.0%로 가장 높고, 나머지는 Electronics 22.5% ~ Sports 27.5%
- 카테고리별 판매량은 199,327 ~ 200,922건으로 거의 같음 (할인율이 가장 높은 Clothing 199,824건, 가장 낮은 Electronics 200,038건)
- 할인율과 판매량의 상관계수: Pearson -0.159 (p=0.798), Spearman -0.600 (p=0.285)
- 카테고리가 5개뿐이라 상관계수의 신뢰도가 낮고, 두 값 모두 유의하지 않으므로 결론이 아닌 참고 자료로만 해석함
- **결론:** 할인율이 높은 카테고리가 더 많이 팔린다는 근거가 없음


## 종합 결론
분석 결과 반품과 연결된 신호는 두 가지였고, 둘 다 점진적 증가가 아니라 특정 지점에서 뛰는 **계단형**이었다.

1. **최장 배송 기간(6일):** 반품률이 약 10.6%에서 20.7%로 상승 (6일 배송이면 반품 오즈 약 2.2배)
2. **낮은 상품 평점(3점 미만):** 반품률이 약 11%에서 31~43%로 상승 (다만 전체 주문의 약 3%)

판매자 평점과 할인율은 반품과 거의 관계가 없었고, 카테고리는 통계적으로 유의했으나 효과가 무시할 수준(Cramér's V 0.0054)이었다.

판매량(브랜드, 월별, 지역, 판매자 평점 구간, 카테고리 할인율)에서는 어느 기준으로 봐도 의미 있는 차이가 나타나지 않았다. 변수들이 반품과 판매량을 거의 설명하지 못하고(Pseudo R² 0.0133) 값이 고르게 분포한 것은 합성 데이터의 특성일 가능성이 크며, 실제 이커머스 데이터로 일반화하기는 어렵다.

> 이 분석은 변수 간 **상관관계**를 보여줄 뿐, 배송 기간이나 평점이 반품의 **원인**이라는 인과를 증명하지는 않는다.
